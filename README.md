One office joke for make.fun's "Make the AI Judge Laugh": a single line
of at most 200 characters about office life — the Wi-Fi goes down and,
for the first time ever, everyone in the office actually makes eye
contact.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–200 characters), and writes the same bytes on every run.
